# Fluffy ✨ - Liquid Glass Notes App

تطبيق تدوين ملاحظات فاخر مبني بأحدث تقنيات **Liquid Glass** و **Frosted Glass** مع التشتت اللوني وانكسار الضوء (Chromatic Dispersion) والظلال الداخلية (Inner Shadow) ودعم الوضع الليلي والنهاري بالكامل.

---

## 🚀 نظام النشر التلقائي في خانة الـ Releases

تم إعداد نظام **GitHub Actions CI/CD** تلقائي بالكامل في المسار:
`.github/workflows/release.yml`

### كيف يعمل النظام عند عمل Push؟
1. **استخراج رقم الإصدار تلقائياً**:
   يقوم مسار العمل بقراءة `versionName` من ملف `app/build.gradle.kts` (مثلاً: `1.0.0`).
2. **بناء وتسمية الـ APK**:
   يتم بناء حزمة التطبيق تلقائياً وتسميتها بالصيغة المطلوبة:
   `Fluffy.v1.x.x.apk` (مثال: `Fluffy.v1.0.0.apk`).
3. **حذف النسخ القديمة تلقائياً**:
   يقوم الإجراء بحذف جميع الإصدارات والـ Tags السابقة من خانة **Releases** في GitHub بحيث تبقى دائماً النسخة الأحدث فقط نظيفة وجاهزة للتحميل.
4. **نشر النسخة الجديدة في Releases**:
   يتم إنشاء Release جديد في GitHub ويحتوي على ملف `Fluffy.v1.x.x.apk` مباشرة.

## 🔄 كيفية رفع إصدار جديد (تغيير رقم الإصدار)

عندما ترغب في رفع تحديث جديد، كل ما عليك هو تعديل رقم الإصدار في `app/build.gradle.kts`:

```kotlin
defaultConfig {
    versionCode = 2
    versionName = "1.0.1" // أو 1.1.0 ...
}
```

ثم عمل **Push** إلى مستودع GitHub (عبر زر Push to GitHub في قائمة الإعدادات). سيقوم النظام فوراً بما يلي:
- بناء `Fluffy.v1.0.1.apk`
- حذف الإصدار السابق `v1.0.0`
- نشر الإصدار الجديد `v1.0.1` مع ملف `Fluffy.v1.0.1.apk`.
